# Canonical Integration Lock

Mission Dark is a presentation client for the existing VIGIA runtime. `127.0.0.1:4177` remains authoritative.

## Non-negotiable

The frontend may normalize canonical responses into view models. It may not invent operational state to fill visual gaps.

Forbidden runtime substitutes include:

- fixture/current fires;
- generated or cropped satellite/fire imagery;
- stock/reference apparatus presented as live resources;
- fake firefighter identities or positions;
- fake Mayday, containment, water, CAD/AVL, ETA or public-warning state;
- unqualified physical-mesh claims.

Missing integrations fail closed with explicit product states.

## Presentation stability

Real data adapts to the approved UI through truncation, bounded scroll regions, disclosure and explicit empty/degraded states. Route geometry must not expand unpredictably because a backend field is long.
