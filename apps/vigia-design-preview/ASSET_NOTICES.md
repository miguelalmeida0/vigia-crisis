## Original application code

## Reference map assets

`assets/national-reference.webp` and `assets/local-reference.webp` are map-only crops from the user-provided visual design references:

- `painel_nacional_de_incêndios_em_portugal.png`
- `painel_de_inteligência_territorial_em_gaia.png`

They are illustrative design assets, not a current satellite dataset. Baked-in numeric totals in the national reference crop were removed to avoid conflicts with the app's sample totals. Some labels and symbols remain part of the raster image.

Their use here is confined to the requested local design review. This package does not establish independent licensing for production redistribution of underlying third-party basemap material. Replace reference rasters with an approved map provider before deploying a real service.

No remote font, icon, map, API or analytics request is required to run this preview. No font files are distributed.
