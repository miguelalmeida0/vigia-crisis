# External practitioner evaluation protocol

The executable package is generated by `npm run operator-eval:prepare`. It defines ten critical tasks, trial traces, environment outcomes, consent, de-identification, graders, and a machine-readable result import.

The evidence gate requires 10 real sessions with at least 5 emergency practitioners and 3 operational perspectives. Passing requires at least 90% critical-task completion, zero dangerous misinterpretations, median top-incident time below 45 seconds, median WHY time below 75 seconds, median handoff below 4 minutes, and clarity/trust at least 4/5.

Participants must consent before collection. Result exports must use study identifiers, contain no names or direct contact details, support withdrawal, and retain complete task and environment traces. VIGIA must not generate or simulate participant records.

After the study, place the governed results JSON in the repository evidence intake location and run:

```sh
npm run operator-eval:prepare -- --results=<governed-results.json>
```

An independent safety grader must adjudicate dangerous misinterpretations before the result can pass.
