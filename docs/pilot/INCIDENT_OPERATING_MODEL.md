# Incident operating model

The only operational truth classes are `VERIFIED_CURRENT`, `DETECTION_CANDIDATE`, `NEEDS_REVALIDATION`, and `HISTORICAL_CLOSED`. `OPEN` is lifecycle, never verification. Only `VERIFIED_CURRENT` counts as active.

Operators move through Detect → Verify → Anticipate → Respond → Protect / Recover → Learn. Each stage requires a distinct persisted object. Thermal pixels are observations, not perimeters. Terrain and proximity are context, not evidence of impact. Regional weather is never upgraded to incident evidence. Forecast geometry remains withheld until the scientific admission contract passes.

Priority is a deterministic routing order from admitted factors. The factors, missing factors, evaluated time, revision, and why-ranked-above-next statement are inspectable. A score is not probability or risk truth.
