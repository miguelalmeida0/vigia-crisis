# Independent red-team brief

Attack these claims using the final release and evidence bundle: false verification; stale-source promotion; duplicate-family inflation; attention over-compression; authority bypass; replay/live/exercise contamination; map/incident mismatch; incorrect weather association; thermal/perimeter conflation; causal outcome overclaim; and resource or alert dispatch without a receipt.

For each case record setup, actor/scope, exact request or UI action, expected fail-closed behavior, observed behavior, artifact hash, severity, and disposition. Do not lower a gate or edit generated evidence. The independent assessor must sign the final finding register; the implementer’s automated negative controls are inputs, not independent approval.
