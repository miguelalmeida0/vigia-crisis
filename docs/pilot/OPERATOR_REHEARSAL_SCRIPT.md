# Operator Rehearsal Script

## Before each rehearsal

1. Confirm the facilitator and operator names, controlled session ID, release ID, code-state hash, migration head `015`, browser certificate, and permitted SHADOW universe.
2. Read `PROHIBITED_USE.md` aloud. Confirm that no external operational action will be taken.
3. Confirm the console starts on Overview, shows one release identity, and exposes only Overview, Detect, Evidence, Handoff, Prevent screening, Source Health, FieldNet, Incident Replay, and Settings.
4. Stop if the console, backend, FieldNode, manifest, database contract, or browser identity disagrees.

## Five controlled rehearsals

### 1. Truth-first event review

From Overview, explain physical truth, public-report state, source health, evidence gaps, and the highest-priority work. In Detect, select three distinct real Portugal events. For each, identify the event ID, location, physical source families, freshness, contradictions, missing evidence, and Now/Next/Why. Record confusion and task completion only from direct observation.

### 2. Evidence and failure-state review

Carry one selected event into Evidence and Handoff. Confirm selection continuity, attributable sources, unresolved-only counts, and no more than twenty primary handoff entries. The facilitator introduces controlled event, source, FieldNet, and map failures. The operator must name `STALE`, `FAILED`, `UNAVAILABLE`, or `MAP VISUALIZATION DEGRADED` and refuse to treat retained values as current.

### 3. PREVENT epistemic-boundary review

Review a real governed scene pair at 20%, 80%, and by direct comparison. Open a measurement-required finding. The operator must state that estimates are withheld, no decision-grade geometry exists, and no treatment recommendation or authority has been created.

### 4. Provenance-bound manual import

Using an isolated facilitator-supplied SHADOW file, validate and preview without confirmation first. Explain adapter, sanitized filename, source hash, accepted/rejected rows, and `MANUAL_SHADOW_NOT_LIVE_SYNCED`. Confirm only if the facilitator has designated this rehearsal for a durable isolated write. Compare the final receipt with the preview and record any discrepancy. Never use real operational records.

### 5. Continuity, replay, and handoff

Review FieldNet as software-only continuity, including central current/stale state, conflicts, acknowledgement, and unknown unsynced work. Use Incident Replay by keyboard and confirm focus continuity. Create an integrity-bound handoff snapshot only from a current runtime. Explain what remains unknown and what the next human operator must verify.

## Stop conditions

Stop immediately on identity mismatch, authorization bypass, executable hostile text, wrong-incident access, stale-as-current language, false physical evidence, unsupported resource/personnel claims, unbounded primary work, inaccessible critical navigation, or any high/medium security finding affecting the pilot/runtime path.

## After each rehearsal

Complete `REHEARSAL_SCORECARD.md` using observed facts only. Preserve the controlled evidence references. Do not infer satisfaction, trust, speed, correctness, or success from missing responses.
