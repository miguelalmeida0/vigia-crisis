# VIGIA government-pilot overview

VIGIA is wildfire operational intelligence and decision support. The pilot evaluates whether a named incident-command team can use governed source evidence, incident truth, maps, assignments, protection review, handoff, and audit export without confusing availability, freshness, verification, scientific admission, work state, or authority.

The pilot must use one immutable release identity quartet and the canonical local runtime. It is not authorized for public alert delivery or external resource dispatch. Detection candidates do not count as active incidents; only `VERIFIED_CURRENT` records do. Exercise, replay, and live-production evidence universes remain structurally separate.

The release includes 207/207 governed terrain and point-context projections and a real collection-closure cohort. A government pilot remains no-go until named authority, legal/data terms, provider credentials where required, and a completed human EOC exercise meet [PILOT_ACCEPTANCE_CRITERIA.md](PILOT_ACCEPTANCE_CRITERIA.md).
