# Controlled EOC exercise plan

Use `CONTROLLED_EOC_EXERCISE`. Start one operational period, assign all six roles and incident ownership, acknowledge objectives, record a decision point and tactic, create an assignment and resource, acknowledge both assignment and action, run the protection approval and valid CAP-draft path with external send disabled, record expected and observed postconditions, classify the outcome, complete acknowledged handoff, and close with an after-action finding.

The facilitator records role transitions, task start/end, errors, backtracking, missed acknowledgements, and any incorrect interpretation. The outcome may be `SUCCESS`, `PARTIAL`, `FAILED`, `INDETERMINATE`, or `INSUFFICIENT_EVIDENCE`; do not force success.

The automated release rehearsal proves persistence and isolation only. It does not satisfy the human exercise gate. Use [OPERATOR_TRAINING.md](OPERATOR_TRAINING.md) before the named human run.
