# Kill switch and safe mode

If source identity, universe separation, map/incident association, authority, storage integrity, or release identity becomes uncertain, stop mutations and external transport. Preserve read-only last-good content, surface the precise degraded axis, and retain audit data.

FieldNet may continue incident-scoped offline work only when authoritative local readiness remains true. Protection/public-alert and external resource dispatch remain disabled. Resume mutation only after a named incident commander or authorized administrator verifies the failed precondition and records the decision.
