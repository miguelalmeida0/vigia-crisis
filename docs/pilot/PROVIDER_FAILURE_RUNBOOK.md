# Provider failure runbook

1. Identify the provider, source family, health, last successful receipt, last attempt, failure class, next check, and affected incident/requirement count.
2. Preserve last-good operator content and keep availability separate from freshness and verification.
3. Let bounded retries follow the recorded strategy; do not manually create evidence.
4. On credential/authority failure, assign the provider-level attention item to an authorized administrator.
5. On no coverage, retain the requirement and next check. Absence is not a negative observation.
6. On contract rejection or conflict, quarantine the record and escalate with the receipt.
7. Close only after qualifying evidence is admitted or a documented terminal condition is reached.
