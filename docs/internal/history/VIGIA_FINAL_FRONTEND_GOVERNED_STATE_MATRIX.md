## Contract closure

- Categories A–C: the Evidence and Intelligence adapter/rendering defects are fixed and covered by static regression tests.
- Category D: `governedWork` is now a backend-owned operator projection. It joins Evidence Needs to Evidence Debt authority fields, maps canonical operator language, and preserves source state, reason, ranking, and provenance.
- Categories E–F: UI consumers render explicit unavailable/degraded truth. Acceptance evidence may show the honest absence, but cannot claim the unavailable condition occurred.
