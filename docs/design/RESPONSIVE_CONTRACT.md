# Responsive Contract

## Required widths

- 1672
- 1440
- 1280
- 1024
- 768
- 430
- 390
- 320

## Mode changes

### Full desktop

Persistent navigation may remain. Dominant object and rails match locked composition.

### Compact desktop

Reduce gaps and low-priority metadata. Do not shrink typography aggressively.

### Tablet landscape

Collapse or narrow persistent navigation. Move secondary rails below dominant surfaces when needed. Reduce table columns by priority.

### Tablet portrait

No full desktop sidebar. Maps/graphs full width. Use intentional 1–2 column compositions.

### Mobile

Single-column task flow. Replace desktop tables with compact operational rows. Keep critical context near the top. Use drawers for navigation and detail. Do not create nested scroll traps.

## Assertions

- No page horizontal overflow.
- No accidental overlap.
- No clipped control labels.
- No offscreen primary action.
- No zero-height visualization.
- No desktop-only interaction.
- Minimum touch target 44px.
