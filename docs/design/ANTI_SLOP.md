# Anti-Slop Reference

This document expands the root blacklist. It is read on demand by design skills.

## Statistical defaults to challenge

- Default font + default icon library + default card component.
- Centered everything.
- Three equal cards.
- Purple/blue gradient.
- Giant rounded containers.
- Mono uppercase labels above every section.
- Dashboard metrics displayed as decorative cards.
- Repeated pills, badges, and status dots.
- Faux premium beige/gold/serif system.
- Faux technical dark grid/glow system.
- Large empty whitespace without hierarchy.
- Explanatory copy compensating for unclear interaction.
- Adding settings rather than designing a sensible default.
- Adding a modal when inline or direct action is possible.
- A new component variant instead of simplifying the component model.

## Product-specificity test

Before shipping, remove the logo and product name mentally. If the page could belong to any random AI startup, admin template, or dashboard kit, the art direction is insufficient.

## Functionality test

Before adding a visual element, state its product function. If the answer is only “looks premium,” remove or redesign it.

## Repetition test

Count repeated:

- card treatments;
- eyebrow labels;
- pill styles;
- shadow styles;
- section layouts;
- CTA intents;
- icon metaphors.

Repetition should communicate system, not reveal generation habits.
