# Mega V implementation contract

VIGIA supports operators interpreting wildfire incidents under pressure. The map remains the dominant object; incident state/action is primary, relevant facilities/routes and source age support it, and provenance/history remain disclosures. This sprint preserves the approved light canvas, typography, six routes and existing drawers. Design variance 1/10, motion 1/10, density 7/10; operational risk is high. No new page or visual pattern is planned.

The flow under test is: authenticated incident entry → useful map → Fire Activity → Response & Access → facility / Ask → sourced capability and qualified road information. Global first visits, incident switching and responsive behavior are measured separately. Browser plugin is not listed; the existing pinned Playwright container provides repeatable measurements and rendered verification.

Road observations retain provider identifiers, geometry, direction, original observation/start/end times and ingestion time. A point notice is not a whole-road closure. New source facts use existing canonical entities, authority admission and temporal snapshots. Designation never implies activation. Models remain disabled until actual startup and corpus evidence justify their bounded use.

Audit investigation must preserve all historical bytes and report discontinuities. Repairs prevent new malformed receipts; they cannot manufacture historical verification. Readiness is never weakened.
