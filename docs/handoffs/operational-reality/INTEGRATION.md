# Operational Reality integration contract

The six-route composition remains frozen. Currentness answers which records still deserve attention independently of verification. Command and National summaries reuse their current count roles; Incidents reuses its existing status dropdown with operational queue, current, monitoring, review and history filters. The incident name/status roles carry currentness, while source verification stays separately available.

Existing physical metrics, What changed lists and support tables carry attributable thermal age/distance, applicable warnings and nearest mapped geography. Existing Ask results answer typed domain questions. Existing work disclosures carry task suspension reasons and retained transitions. No new page sections, cards, navigation or map renderer.

Observation age uses observedAt; transport delay uses receivedAt minus observedAt; display delay uses displayedAt minus receivedAt. None substitutes for the other. Queue windows and materiality thresholds are operational configuration, never fire-danger thresholds.
