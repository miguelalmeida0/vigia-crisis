# Persistent world intelligence

The sprint extends the existing intelligence module and PostgreSQL/PostGIS pool. The missing domain is canonical public entities and source-derived field assertions; incident snapshots, weather, FIRMS, response routing and existing spatial admission remain their owners.

Approved source documents produce bounded candidate assertions with supporting passages. Deterministic source rules and validation admit assertions; the local model proposes only. A canonical field resolver preserves precedence, equal-authority conflicts, temporal validity and source lineage. Entity matches require evidence; branch ambiguity prevents merging.

PostgreSQL stores canonical entities, source documents, assertion history, durable jobs and explicit relationships. File storage exists for deterministic tests/offline development only. UI reads materialized persisted entities through existing facility/incident projections, never inference. Source changes mark dependent relationships/routes stale and enqueue recalculation. Workers poll only registered exact URLs and stop on unchanged content.

UI scope: feed the existing facility sheet richer name, type, structured address, contact and field provenance. Hide capability fields whose canonical type marks them not applicable. Preserve shared sheet anatomy, all routes and map distinctions. Distances identify reported incident point. Add the official website action beside existing contact/map actions; conflicts remain in existing source disclosure.

Acceptance evidence tracks source ingestion, extraction, admission, resolution, persistence/restart, API projection, type-aware sheet rendering, source-change invalidation, AI offline and rejected output. Pilot denominators include unresolved cases and distinguish authoritative address recovery from total address coverage. No model-only operational fact or paid inference provider is admissible.
