# Supervised operator rehearsal

Run `npm run rehearsal:open` while the certified 4177, 4188, and 4190 services are running. The command verifies the backend and exact release, creates a protected session pack under `.tmp/operator-rehearsal`, and opens the one-time admitted Operator Console on Overview.

The facilitator must use the Settings rehearsal controls to start a session, add one task marker per task, record direct observations, and export JSON plus CSV. Live incidents remain live; historical cases are used only through the explicitly labelled Replay route. No synthetic participant, AI persona, fixture, or facilitator inference counts as human evidence.

Five real sessions, including at least three emergency-domain practitioners, are required before the human-validation gate can pass. The thresholds in the generated pack are release gates, not results.
