## P2 — misleading precision, hidden fallback, or scope ambiguity

| Surface | Why it misleads | Correction |
|---|---|---|
| `sourceFamily` / `independenceGroup` described as independence | Producer/config string is not proof of statistical independence or separate processing lineage. | Show lineage and dependency evidence; call it declared grouping. |
| Native sensor confidence converted to `.85/.65/.35` or `1/.72/.3` | These conversions are arbitrary quality weights used in association/candidate screening. | Keep native value/definition; do not normalize across sensors without calibration. |
| Thermal support convex hull | It can include unobserved territory and nominal rectangles ignore scan orientation. Code caveat is good, but map visual may still read as a perimeter. | Use hatched pixel footprints, avoid perimeter-like styling, show observation support count/time. |
| Centroid “movement” | It is a shift of detection centroids, not front direction/speed. | Keep full limitation beside every rendered value. |
| Source/demo product selected as default MTG context | “MTG observed” can be read as fire observed, although it means a current raster layer exists. | `MTG raster timestamp`; never imply selected event observation. |
| Persistent event identity | Stable only for retained observations/mappings; manual bindings are deleted when observations age out and writes can fail silently. | Define retention and durability boundaries in UI/API. |
| Evidence checksum | A SHA hash detects local payload change only if a trusted original exists; it is not signature, provenance, or immutability. | Label `content checksum`; add signed ingest + immutable object version. |

## Claims that are appropriately bounded and should be preserved

These statements were supported by code and runtime behavior and are not broken:

1. **A recent report is not a current physical observation.** The state model and UI keep the clocks separate (`packages/domain/src/fire-event-state.mjs:15-33`, `apps/web/src/v2/views/live.js:8`).
2. **WMS raster context is not point evidence.** The event UI said this and the event service does not automatically convert the overlay into detections.
3. **Browse/cross-sensor imagery cannot enable scientific screening.** The Mirandela request abstained and the UI labelled the fallback broad context.
4. **Thermal support is not an authoritative perimeter.** Geometry properties and limitations are explicit (`packages/domain/src/fire-event-geometry.mjs:14-20`).
5. **No event-existence probability without validated calibration.** Fusion returns null (`packages/domain/src/evidence-fusion.mjs:19-34`).
6. **Prevention priorities are not detected hazards.** Public UI and API say this, and no fixture finding leaked into public mode.
7. **Sentinel-2 resolution cannot certify object-scale conditions.** The policy abstains and the UI exposes escalation (`packages/domain/src/sensor-resolution-policy.mjs:9-15`).
8. **Official civil-protection instructions take precedence.** This is a valid scope statement, though it does not cure the P0 defects.

## Product-language conclusion

The product is most trustworthy when it says “unknown,” “unobserved,” “context only,” “screening,” or “not a perimeter.” It becomes unsafe when it promotes local plumbing into identity, immutability, SLA, probability quantiles, independent proof, measured outcomes, or available acquisition. Delete those promotions first; do not cosmetically soften them while leaving the underlying semantics unchanged.
