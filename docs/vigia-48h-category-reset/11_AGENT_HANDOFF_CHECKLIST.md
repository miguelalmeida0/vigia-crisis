# Agent Handoff Checklist

The top agent should not finish with "foundation complete."

## Required final report

### Release verdict

PASS / PARTIAL / BLOCKED

### Mission proof

Show:

- pre-ignition physical candidate
- ignition/thermal candidate
- Living Fire
- Action closure

### Exact Git checkpoints

List commits.

### Exact real sources

For each:
live / historical / blocked / unavailable.

### Exact detector results

No screenshots-only claims.

### Validation

- run ID
- commit
- corpus
- metrics
- unmeasured

### QA

- tests
- browser
- geo
- PostGIS
- restart
- responsive
- source degradation

### Screenshot evidence

At minimum:

### Setup required from user

Only actionable items:

- credential name
- where to obtain
- where to set
- what capability it unlocks

### Exact commands to run

Include all commands.

### Working tree

Clean.

## Final questions the agent must answer

1. Does VIGIA now detect any pre-ignition physical condition?
2. Does VIGIA now create a physical fire event without a public report?
3. Does the home screen still look like a report dashboard?
4. Does a selected fire show real physical evolution?
5. Does every major claim have provenance?
6. Does uncertainty create work?
7. What remains impossible because of external credentials/data?
8. Which metrics are still unmeasured?
9. What is the single next highest-leverage move?
