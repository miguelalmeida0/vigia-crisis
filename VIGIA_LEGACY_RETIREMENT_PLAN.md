# VIGIA legacy retirement plan

| Legacy or overlap | Current disposition | Retirement condition |
|---|---|---|
| Agent 1 operational incident projection | Compatibility adapter only; SYSTEM-class and non-witnessing | Native provider, CAP, FIRMS and FieldNet adapters cover every active signal and replay parity is proven. |
| Agent 1 immutable intelligence snapshot ledger | Retained as a reliability/audit ledger, not semantic object authority | Consumers use Decision Foundry objects and historical decision receipts have a verified migration or permanent archive contract. |
| Agent 2 file semantic repository | Single fallback only when PostgreSQL is not configured; never used in parallel with PostgreSQL | All supported profiles require certified PostgreSQL and file-state import/replay is complete. |
| Agent 1 CAP incident projection | Superseded for truth by Event Fabric CAP lifecycle adapter | All configured CAP feeds bind through the canonical adapter and update/cancel/reference parity passes. |
| Browser hardcoded compatibility identity | Retired | Complete: browser reads the immutable release identity generated from the canonical domain contract. |
| Frontend source-health/evidence calculations | Prohibited | No compatibility period; backend projections are normative. |
| Multiple migration 017 histories | Retired through audited alias adoption and forward 022 | Complete when clean, Agent 1 and Agent 2 upgrade databases produce equivalent catalogs. |
| Session-only authority for consequential actions | Transport compatibility boundary only | Runtime trust roots, credentials, delegation and revocation stores are configured and Proof Plane end-to-end action certification passes. |

No adapter may silently become a second truth owner. Every adapter must preserve source identity, knowledge time, provenance, failure state and replay binding.
