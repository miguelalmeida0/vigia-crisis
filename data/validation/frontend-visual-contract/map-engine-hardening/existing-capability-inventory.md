## Activated path

Reports now joins a real authorized incident across the whole mission vocabulary: canonical source observation (`DETECT`) → Operational Twin evaluation (`VERIFY`) → forecast-science boundary (`ANTICIPATE`) → governed evidence/action lifecycle (`RESPOND`) → linked outcome loop if present (`PROTECT / RECOVER`) → measurement row (`LEARN`). Missing acknowledgement, postcondition, or outcome proof is emitted as `NOT_RECORDED`/`NOT_MEASURABLE`; it is never filled with synthetic progress.
